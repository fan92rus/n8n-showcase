# Шаблоны (blueprints) — структурно валидированы, живьём не запускались

Сценарии в этой папке проверены структурным валидатором (`scripts/validate.py`):
узлы, связи, выражения корректны, но на живом n8n-стенде они **не запускались** —
каждый требует ваших учёток (Google Sheets/Calendar, IMAP, CRM, LLM-ключ).

Это шаблоны для внедрения: под ваш стенд адаптируем узлы-подключения и
запускаем живьём за часы, не дни.

| Файл | Сценарий |
|------|----------|
| `01-form-to-sheet-to-telegram.json` (+`01b-error-alert`) | заявки с сайта → таблица → TG-уведомление + сторож ошибок |
| `02-booking-to-calendar.json` (+`02b-reminders`) | онлайн-запись → слот в календаре → напоминания |
| `03-email-ai-to-sheet.json` | IMAP-письма → AI-классификация → таблица → уведомление |
| `04-order-pipeline.json` | заказный webhook-пайплайн с валидацией, VIP-маршрутизацией и идемпотентностью |
| `05-daily-etl-report.json` | ежедневный ETL-отчёт: API → агрегация → AI-резюме → TG |
| `06-link-curator.json` | куратор ссылок из TG-чата: парсинг → AI-теги → публикация в канал |

Живые, проверенные на демо-стенде воркфлоу — в [workflows/](../workflows/).
