# Демо 3: Письмо клиента → AI-разбор → таблица → уведомление

Воркфлоу n8n: каждое входящее письмо на почту компании разбирает AI —
категория, суть, срочность — и попадает в таблицу заявок с мгновенным
уведомлением менеджеру.

## Что внутри

| Файл | Что делает |
|------|-----------|
| `03-email-ai-to-sheet.json` | IMAP-триггер → AI-разбор (строгий JSON: категория/срочность/суть/требует_ли_ответа) → строка в Google Sheets → TG-уведомление |

## Что решает

- Письма не тонут в почтовом ящике: каждая заявка видна в таблице.
- Менеджер сразу видит категорию и срочность — сначала отвечает горящим.
- Спам и рассылки отсеиваются автоматически (категория «спам»).
- При сбое AI письмо всё равно попадает в таблицу с пометкой
  «ошибка разбора» — ничего не теряется.
- Один раз настроили — работает без участия человека.

## Установка (15 минут)

1. Импортируйте JSON в n8n.
2. Подключите: IMAP-аккаунт компании, OpenAI API (или совместимый LLM),
   Google Sheets, Telegram Bot.
3. Замените `ВСТАВЬТЕ_ID_ТАБЛИЦЫ` и `ВСТАВЬТЕ_CHAT_ID_МЕНЕДЖЕРА`.
4. Классификация меняется одной строкой в системном промпте — под ваши
   категории (заявки/счета/поддержка/...).
5. Активируйте. Первое письмо — проверка.

## Адаптация

- Источник писем: Яндекс 360, VK WorkMail, Gmail, любой IMAP.
- Вместо таблицы — AmoCRM/Bitrix24-лид.
- Можно добавить автоответ клиенту «заявка принята» и эскалацию срочных
  на телефон менеджеру.
