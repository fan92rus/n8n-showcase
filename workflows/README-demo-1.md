# Демо 1: Заявка с формы → таблица → Telegram

Готовый workflow для n8n: приём заявок с сайта/лендинга, защита от повторных
отправок, ведение таблицы заявок и мгновенное уведомление менеджера в Telegram.

## Что внутри

| Файл | Что делает |
|------|-----------|
| `01-form-to-sheet-to-telegram.json` | основной воркфлоу: форма → дедупликация → Google Sheets → TG-уведомление |
| `01b-error-alert.json` | отдельный «сторож»: ловит падение любого воркфлоу и шлёт алерт админу |

## Почему это надёжнее «просто формы»

- **Защита от дублей** (Remove Duplicates): повторная отправка формы тем же
  человеком не дублирует запись и уведомление.
- **Идемпотентная запись** (Google Sheets Append or Update по колонке Email):
  повторная заявка обновляет строку, а не плодит копии.
- **Обработка ошибок**: если запись в таблицу упала — менеджер получит алерт с
  данными заявки и причиной, заявка не потеряется.
- **Сторож ошибок** (Error Trigger): отдельный воркфлоу сообщает о падении
  любого рабочего сценария — вы узнаёте о проблеме раньше клиентов.

## Установка (10 минут)

1. Импортируйте оба JSON в n8n (Workflows → Import from File).
2. В основном воркфлоу подключите креденшелы Google Sheets и Telegram Bot.
3. Замените плейсхолдеры `ВСТАВЬТЕ_ID_ТАБЛИЦЫ` и `ВСТАВЬТЕ_CHAT_ID_МЕНЕДЖЕРА`
   (в 01b — `ВСТАВЬТЕ_CHAT_ID_АДМИНА`).
4. В Google Sheets создайте лист «Заявки» — колонки создадутся автоматически
   из полей формы (Имя, Телефон, Email, Сообщение, submittedAt).
5. Активируйте оба воркфлоу. Ссылку формы (Form Testing / Production URL)
   вставьте на свой сайт или дайте клиентам напрямую.

## Адаптация под вас

- Вместо Google Sheets можно подключить AmoCRM/Bitrix24/Notion/Airtable —
  структура воркфлоу не меняется, меняется один узел.
- Можно добавить автоответ клиенту (Email/Telegram) сразу после отправки формы.
