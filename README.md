# n8n-интеграции под ключ

Готовые воркфлоу n8n для малого бизнеса: заявки, записи, письма и уведомления
работают сами. Каждый сценарий — не «демо на пять минут», а рабочий шаблон
с защитой от дублей, обработкой ошибок и понятной инструкцией.

## Живые сценарии (проверены на работающем демо-стенде)

Запущены на нашем n8n-стенде и проверены живыми запросами — можно потрогать
руками в Telegram-боте [@n8n_krenev_demo_bot](https://t.me/n8n_krenev_demo_bot):

| Сценарий | Что делает | Файл |
|----------|------------|------|
| **AI-классификатор заявок** | текст заявки → LLM → категория/срочность/суть (строгий JSON) — попробуйте в боте, просто напишите текст | `workflows/demo-09-ai-classifier.json` |
| **Запись на слоты** | слоты генерируются по рабочим дням, бронь блокирует слот, двойная бронь отклоняется, несуществующие слоты отвергаются — `/slots`, `/book` в боте | `workflows/demo-10-slots-booking.json` |
| **Wizard: подбор услуги (кнопки меняются по шагам)** | 3 шага прямо в одном сообщении: услуга → слот → подтверждение, кнопки перерисовываются на каждом шаге, состояние едет в callback_data (бот stateless), на финале реально бронирует слот — `/wizard` в боте | `workflows/demo-11-wizard-buttons.json` |

Код демо-бота (aiogram-шелл + n8n): [github.com/fan92rus/n8n-demo-bot](https://github.com/fan92rus/n8n-demo-bot)

## Шаблоны для внедрения (blueprints/)

Структурно валидированы, живьём не запускались — требуют ваших учёток.
Адаптируем и запускаем на вашем стенде за часы:

| Сценарий | Уровень | Боль | Решение | Файлы |
|------|---------|------|---------|-------|
| **1. Заявки с сайта** | база | заявки теряются, дублируются | форма → защита от дублей → таблица → TG-уведомление менеджеру + «сторож» ошибок | `blueprints/01-*`, `01b-*` |
| **2. Онлайн-запись** | база | переписка ради выбора времени, неявки | форма → слот в календаре → подтверждение; напоминания каждый день | `blueprints/02-*`, `02b-*` |
| **3. Разбор писем AI** | база | письма тонут в ящике | IMAP → AI-классификация (категория/срочность/суть) → таблица → уведомление | `blueprints/03-*` |
| **4. Заказный пайплайн** | продвинутое | заказы из сайта/1С обрабатываются руками | Webhook API → строгая валидация → VIP-маршрутизация (≥50к) → CRM с идемпотентностью → уведомления | `blueprints/04-*` |
| **5. Ежедневный ETL-отчёт** | продвинутое | руководитель не видит картину дня | расписание → API продаж → агрегация + детект падения ≥10% → алерт → AI-резюме → TG + история | `blueprints/05-*` |
| **6. Куратор ссылок** | продвинутое | годные ссылки из чатов теряются | TG-чат → извлечение ссылок → парсинг страницы → AI (заголовок/суть/теги) → публикация в канал; память уже опубликованного без БД | `blueprints/06-*` |

Каждый сценарий описан в своём README ([blueprints/](blueprints/)) с установкой
за 10–15 минут. Валидатор структуры — `scripts/validate.py`.

## Почему заказывают у нас, а не «сделаю сам по гайду»

- **Обработка ошибок и дубли** — то, о чём гайды молчат. У нас это внутри
  каждого сценария: заявка не теряется при сбое, алерт приходит раньше,
  чем клиент заметил проблему.
- **Адаптация под ваши сервисы**: AmoCRM, Bitrix24, Яндекс Календарь,
  Notion, Airtable, любая почта — структура остаётся, меняется узел.
- **Деплой на вашей стороне**: всё работает в вашем n8n, данные — ваши.
- **Сопровождение**: меняются процессы — меняем сценарий.

## Как заказать

1. Опишите процесс, который хочется автоматизировать (что руками делаете
   сейчас и сколько времени ест).
2. Получите оценку и сроки (обычно 3–7 дней).
3. Через неделю у вас работает сценарий, который экономит часы каждую неделю.

Формат работы: безопасная сделка на FL.ru (оплата после приёмки) или прямой
договор. Контакты: профиль [fan92rus на FL.ru](https://www.fl.ru/users/fan92rus/),
GitHub [github.com/fan92rus](https://github.com/fan92rus).

## Стек и компетенции

- n8n (workflows, error handling, webhooks, schedule, sub-workflows)
- Интеграции: Telegram, Google Workspace (Sheets/Calendar/Gmail), IMAP/SMTP,
  CRM (AmoCRM, Bitrix24), OpenAI/совместимые LLM, произвольные REST API
- Доборные навыки: Python/C# для кастомных нод, Docker для self-hosted n8n

## Честный дисклеймер

Сценарии из `workflows/` проверены живыми запросами на нашем демо-стенде.
Сценарии из `blueprints/` проверены структурным валидатором (узлы, связи,
выражения) и адаптируются под ваш стенд при внедрении — живой прогон
выполняется там же, это часть работы и занимает часы, не дни.
